# Nefa - Free landing page template built using nuxt and tailwindcss
#### Preview

 - [Demo](https://themewagon.github.io/nefa/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/nefa/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/nefa.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
